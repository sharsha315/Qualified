# Qualified
**Gen AI Agents for smarter talent screening**

Qualified is a Python-based Gen AI project designed for the [Hack the Future: A Gen AI Sprint Powered by Data](https://www.geeksforgeeks.org/hack-a-thon/gen-ai-hackathon) hackathon, powered by **GeeksForGeeks** and **Accenture**. 

It leverages a multi-agent system to automate the end-to-end job screening process — from parsing JDs and CVs to shortlisting and scheduling interviews.

---

## 🚀 Features

- 🤖 Multi-agent architecture (JD Agent, CV Agent, Matchmaker, Scheduler)
- 📝 Automated resume parsing from PDFs
- 📊 Match score generation based on skill relevance
- 📬 AI-generated interview invites
- 💾 Persistent storage with SQLite
- 💡 LLM-powered summarization using [Ollama](https://ollama.com/)

---

## 🔧 Technologies

- Python
- LangChain / Custom Agents
- Ollama LLMs (LLaMA3, Mistral, or Phi3)
- PyPDF2 / pdfplumber
- SQLite
- Pandas, spaCy
